# jiikko Homebrew Tap & Docs

`jiikko` の Homebrew tap と、各アプリの公開ドキュメントです。

## Homebrew

```bash
brew tap jiikko/tap
brew install jiikko/tap/tt-client
```

`tt-client` は [ThumbnailThumb](https://jiikko.com/thumbnail-thumb/) の API クライアント（CLI）です。

## ドキュメント

### ThumbnailThumb

- [取り込みフォーマット仕様書](thumbnail-thumb/import-format.html) — ChatGPT 等の LLM に書かせた JSON を貼り付けてキャンバスに要素を一括取り込みするためのフォーマット仕様。
